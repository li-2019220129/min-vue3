51.3 彩蛋：本站发现的三处源码彩蛋

  • 拼写彩蛋：tarckEffect（track 的手滑版）—— 读源码别迷信，作者也是人。
  • 作业彩蛋：RefImpl 的 set 里少了一次 toReactive(newValue)（第 7 章），修掉它，你就给这个项目提了第一个 PR 级别的改动。
  • 侦探彩蛋：traverse 里 if (isObject(source)) return source 会让对象从不被深度遍历（第 50 章 Q24 揭晓）—— 对照官方源码，看看你能不能先于面试官发现它。

51.4 下一站：Vue 3.6 正在路上

本站写作时（2026 年 9 月），官方最新稳定版是 v3.5.43， 而 Vue 3.6 已经进入 RC 阶段 —— 它是继 3.4/3.5 之后的第三次响应式大手术，两件大事：

新变化是什么与本站所学的关系
alien-signals 响应式重写 reactivity 核心基于 alien-signals（StackBlitz 的高性能信号库）推倒重写， 精度高、内存占用更低；对外 API（ref / computed / watch）几乎不变 API 不变 = 你在第 2~12 章学的心智模型全部有效； 内核从「双向链表 + 版本计数」（第 14 章）换成 push-pull 信号图 —— 这已经是响应式内核的第四代实现， 也再次验证了第 6 章那句话：思想不变，换载体而已
Vapor 模式 组件加 <script setup vapor> 即可完全去掉虚拟 DOM： 编译器直接生成「精确到操作」的更新代码，不再有 vnode 和 diff 你学的 patch / diff / Block Tree（第 15~20 章）仍然驱动着非 Vapor 组件； Vapor 则把第 30 章「编译反哺运行时」推到极限 —— 编译期直接知道「改哪个节点」，运行时连 patch 都省了
🧠 三代内核一条线
3.0~3.3「Set + effectStack」→ 3.4「双向链表」→ 3.5「链表 + 版本计数」→ 3.6「alien-signals」。 四代实现，服务的是同一个不变量：「读取时登记，写入时通知，值没变不打扰」。 这就是为什么本站敢用 450 行教学实现带你入门 —— 学的是骨架， 骨架在，肌肉怎么换你都能一眼看懂。3.6 正式发布后，欢迎回到第 14 章做一次「三代对照精读」。
源码不是用来背的，是用来「哦——原来如此」的。
